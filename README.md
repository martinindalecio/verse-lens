# Verse Lens

A Bible reader that explains the world around a passage. Select one or more verses and get:

- **Setting**: who is speaking, to whom, where, and when
- **What's happening around it**: what leads into the passage and what follows
- **Historical and cultural background**: each claim shows what it rests on (the text itself, an ancient source, archaeology, or scholarly reconstruction) and a confidence level
- **Key words** in the original Hebrew, Aramaic, or Greek
- **Cross-references**
- **How traditions read it**: Catholic, Orthodox, Reformed, Jewish, and other readings side by side, clearly labeled as interpretation rather than fact
- **Open questions** where scholars disagree

Scripture text is the [Berean Standard Bible](https://berean.bible/), which is in the public domain. Context is generated by Claude (`claude-opus-5-5`) with structured outputs.

## Run it

```bash
npm install
neon env pull                # writes DATABASE_URL / DATABASE_URL_UNPOOLED to .env.local
node --env-file=.env.local scripts/load-people.mjs   # loads people data into Neon (safe to re-run)
# add ANTHROPIC_API_KEY to .env.local
npm run dev
```

Open http://localhost:3000.

## How it works

| Piece | Where |
| --- | --- |
| Bible text, one JSON file per book | `data/bsb/` (built by `scripts/build-bible.py`) |
| Book list and chapter loading | `src/lib/bible.ts` |
| Context schema (shared by API and UI) | `src/lib/context-schema.ts` |
| Prompt, Claude call, cache | `src/lib/context.ts` |
| API v1 (`/api/v1`): `books`, `books/{book}/chapters/{n}`, `person`, `POST context`, `schema` | `src/app/api/v1/`, helpers in `src/lib/api.ts` |
| Reader and context panel | `src/app/read/[book]/[chapter]/page.tsx`, `src/components/` |

The server looks up the verse text itself and sends the whole chapter to Claude, with the selected verses marked, so the model sees the surrounding text. Results are cached per passage in Postgres. See `docs/DESIGN.md` for the reasoning and `TODOS.md` for what's next.

## Regenerating the Bible data

```bash
curl -LO https://raw.githubusercontent.com/scrollmapper/bible_databases/master/formats/json/BSB.json
python3 scripts/build-bible.py BSB.json
```

Built with Next.js 16 (App Router, Cache Components) and Tailwind CSS 4.
